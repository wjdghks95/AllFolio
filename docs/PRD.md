## 🎯 핵심 정보

**목적**: 주식·코인·현금으로 흩어진 자산을 KRW 기준 한 화면에서 통합 조회하고, 추가 매수(물타기) 시 예상 평단가를 즉시 계산해준다.
**사용자**: 증권사 앱·거래소 앱·은행 앱을 3개 이상 따로 사용하며 전체 자산 비중을 파악하지 못하는 개인 투자자.

## 🚶 사용자 여정

```
1. 로그인 페이지 /login (비로그인 시 자동 진입 — 보호 경로 접근 시에도 /login으로 리디렉션)
   ↓ 이메일/비밀번호 입력 후 로그인

   [계정 없음] → 회원가입 페이지 /signup → 가입 완료(자동 로그인) → 2번으로
   [계정 있음] → 로그인 성공 → 2번으로
   ↓

2. 총 자산 페이지 /portfolio (홈 — 통합 자산 조회)
   ↓ "자산 등록" 버튼 클릭

3. 자산 등록 페이지 /assets/new
   ↓ 등록 완료

   총 자산 페이지로 복귀 (신규 자산 반영)
   ↓ 자산 목록에서 항목 클릭

4. 자산 상세 페이지 /assets/:id (실시간 차트 + 내 평단가 + 물타기 시뮬레이터)
   ↓ 보유 수량/평단가 수정 또는 자산 삭제

   완료 → 총 자산 페이지로 복귀
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F001]** | 자산 등록 | STOCK/COIN/CASH 자산과 최초 보유 수량·평단가를 등록 | 자산 데이터 없이는 통합 조회 자체가 성립하지 않음 | 자산 등록 페이지 |
| **[F002]** | 자산 상세 조회 | 개별 자산의 티커·유형·통화·보유수량·평단가 조회 | 개별 종목 확인은 투자 판단의 기본 단위 | 자산 상세 페이지 |
| **[F005]** | 통합 포트폴리오 조회 | 전체 자산을 KRW 기준으로 환산해 평가금액·비중(%)·미실현 손익 표시 | 핵심 문제(여러 앱에 흩어진 자산 파악 불가)를 직접 해결 | 총 자산 페이지 |
| **[F006]** | 물타기(추가 매수) 시뮬레이터 | 추가 매수 단가·수량 입력 시 예상 평단가와 비중 변동을 계산(DB 미저장) | 서비스의 핵심 차별화 가치 | 자산 상세 페이지 |
| **[F007]** | 실시간 시세 차트 + 내 평단가 표시 | 실시간 갱신되는 시세 차트 위에 내 평단가 수평선을 함께 표시 | 손익 상황을 직관적으로 파악 | 자산 상세 페이지 |

> **F005 구현 순서 참고**: 평가금액·비중(%)·미실현 손익 계산에는 종목 현재가와 환율(둘 다 외부 API)이 필요하다. 외부 연동 전까지는 취득원가(`avg_price × quantity`) 합계만 제공하고, 평가금액·비중·손익은 외부 시세 연동 이후 채워진다. `docs/ROADMAP.md`는 이 둘을 각각 F005a(취득원가, Task 013)·F005b(평가금액·비중·손익, Task 023)로 구분해 진행 상황을 추적한다.
>
> **화면 구성 변경 (Task 009)**: 홈 화면 명칭이 "포트폴리오"에서 **"총 자산"**으로 바뀌었고, 자산 목록은 투자 자산(주식·코인)·현금 자산 두 그룹으로 나뉜다. 목록 행에는 평가금액·손익·수량만 표시하고, **비중(%)·평단가·취득원가는 자산 상세 화면(F002, Task 011)으로 이관**됐다 — 총 자산 화면은 "전체가 얼마인가"에, 자산 상세 화면은 "이 종목의 모든 정보"에 집중한다.

## 🗄️ 데이터 모델

|------|------|----------|

### assets (등록 자산)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |

| name | 종목명 (예: 삼성전자) | VARCHAR |
| asset_type | 자산 유형 (STOCK/COIN/CASH) | VARCHAR |
| currency | 통화 (KRW/USD) | VARCHAR |
| created_at | 등록 일시 | TIMESTAMPTZ |

### holdings (보유 정보)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|

| asset_id | 대상 자산 (자산당 1행) | → assets.id |
| quantity | 보유 수량 | NUMERIC(28,8) |
| avg_price | 평단가 | NUMERIC(28,8) |
| version | 낙관적 잠금 버전 | INT |
| updated_at | 최종 수정 일시 | TIMESTAMPTZ |

### transactions (매매 이력)
| 필드 | 설명 | 타입/관계 |

| price | 거래 단가 | NUMERIC(28,8) |
| quantity | 거래 수량 | NUMERIC(28,8) |
| traded_at | 체결 일시 | TIMESTAMPTZ |

### price_snapshots (시세 스냅샷)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | BIGINT |
| ticker | 종목 코드 | VARCHAR |
| price | 시세 | NUMERIC(28,8) |
| captured_at | 수집 일시 | TIMESTAMPTZ |
